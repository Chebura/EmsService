# Описание unit-тестов

Документ описывает тест-кейсы для проекта `EmsService`. Идентификатор кейса совпадает с префиксом имени
тестового метода (например, `S01` → `S01_NullConfiguration_Throws`).

Тесты разбиты на группы:

- **S** — `EmailMassSendingService` (подготовка задач и отправка писем); перенесены из `EmailMassSender.Tests`;
- **H** — `EmsSettingsStore` (хранение и проверка настроек);
- **W** — `EmsWorker` (запуск и остановка рассылки).

Тесты работают с файловой системой во временной директории и не используют реальный SMTP-сервер.
Отправка проверяется либо с отключённым SMTP (`SmtpClient.Enable = false`), либо через локальный фейковый
SMTP-сервер.

Тесты R01–R08 (`EmailMassSendingHostRecycler`) не перенесены: в EmsService повторный запуск через
`HostRecycle` заменён ожиданием ближайшей повторной попытки внутри прогона (SRS, F-RUN-5, F-RUN-6).

## S. EmailMassSendingService

### Конструктор

| ID  | Сценарий | Исходные данные | Ожидаемый результат |
|-----|----------|-----------------|---------------------|
| S01 | Конфигурация не передана | `configuration = null` | `ArgumentNullException` |
| S02 | Некорректное число потоков | `Threads = 0` | `Threads` становится `1` |
| S03 | Нет стратегии повторной отправки | `RollUpStrategy = null` | Создаётся стратегия по умолчанию: `Enable = false`, `Delay = 0`, `MaxCount = 1` |

### Подготовка задач

| ID  | Сценарий | Исходные данные | Ожидаемый результат |
|-----|----------|-----------------|---------------------|
| S04 | Нет групп | `Groups = null` | `SendAsync` завершается без ошибок, файлы задач не создаются |
| S05 | Создание файла задачи | одна группа, 2 получателя | Создаётся файл `<группа>_<MD5 текста>.task`, в нём 2 элемента |
| S06 | Дубликаты получателей | получатели `a`, `a`, `b` | В задаче 2 элемента |
| S07 | Фильтр групп через `DefaultGroups` | группы `g1`, `g2`, `g3`; `DefaultGroups = "G1;g3"` | Задачи созданы только для `g1` и `g3` (регистр не важен) |
| S08 | Все группы | `DefaultGroups = "*"`, `null` или `""` | Задачи созданы для всех групп |
| S09 | Нет получателей | `Receivers = null` | Файл задачи не создаётся, исключения нет |
| S10 | Нет файла с текстом | `PlainTextFileName` указывает на несуществующий файл | Группа пропускается, остальные обрабатываются |
| S11 | Директория задач отсутствует | `TasksPath` не существует | Директория создаётся |
| S12 | Удаление устаревших задач | `DeleteObsoleteTasks = true`, в директории старый `.task` | Старый файл удалён, свежий сохранён |
| S13 | Устаревшие задачи не удаляются | `DeleteObsoleteTasks = false` | Старый файл сохранён |
| S14 | Нет SMTP-настроек | `SmtpClient = null`, есть задачи | `InvalidOperationException`; файлы задач закрыты до выброса исключения |

### Обработка задач (SMTP выключен)

| ID  | Сценарий | Исходные данные | Ожидаемый результат |
|-----|----------|-----------------|---------------------|
| S15 | Обработка при выключенном SMTP | `SmtpClient.Enable = false` | У всех элементов заполнен `Attempt`, `Failed = false`, `Failure = "Not sent (disabled)"` |
| S16 | Повторное использование задачи | файл задачи существует, элемент уже отправлен | Элемент не обрабатывается повторно |
| S17 | Сброс задач | `ResetTasks = true`, элемент уже отправлен | Задача пересоздаётся, элемент обрабатывается снова |
| S18 | Счётчик попыток | `RollUpStrategy.Enable = true`, `MaxCount = 5` | После обработки `AttemptsLeft = 4` |
| S19 | Попытки исчерпаны | элемент с `AttemptsLeft = 0` и `Failed = true` | Элемент не обрабатывается |
| S20 | Истёк срок актуальности | элемент с `Lifetime` в прошлом | Элемент не обрабатывается |
| S21 | Ожидание повтора (изменён) | элемент с `WaitFor` через час, попытки есть | Элемент не обрабатывается; прогон не завершается, а ждёт повтора до отмены |
| S22 | Несколько потоков | `Threads = 3`, 10 получателей | Все 10 элементов обработаны |
| S28 | Повторная отправка выключена (новый) | `RollUpStrategy.Enable = false` | Получателю даётся одна попытка: `AttemptsLeft = 0` |
| S29 | Повреждённый файл задачи (новый) | файл задачи одной группы — не JSON | Задача пропускается, прогон завершается, другая группа обработана |

### Отправка через SMTP (фейковый сервер)

| ID  | Сценарий | Исходные данные | Ожидаемый результат |
|-----|----------|-----------------|---------------------|
| S23 | Успешная отправка | сервер принимает письма | Сервер получил письма всем получателям; `Failed = false`, `Failure = null` |
| S24 | Содержимое письма | тема, текст, отправитель | `MAIL FROM` — адрес отправителя, `RCPT TO` — получатель, тема и текст в письме |
| S25 | Ошибка отправки (изменён) | сервер закрывает соединение; `Delay = 10 мин`; прогон отменяется через 3 с | Одна попытка; `Failed = true`, `Failure` заполнен, `AttemptsLeft = 2`, `WaitFor` = время попытки + 10 мин |
| S26 | Повторы до исчерпания попыток (изменён) | сервер всегда отклоняет; `MaxCount = 3`, `Delay = 300 мс`; без `HostRecycle` | Прогон сам выполняет 3 попытки и завершается, `AttemptsLeft = 0` |
| S27 | Отмена | сервер не отвечает, токен отменяется через 500 мс | `SendAsync` завершается без зависания, файлы задач закрыты |
| S30 | Остановка посреди прохода (новый) | 20 получателей, задержка 200 мс, отмена через 1 с | Число отправленных в файле задачи равно числу писем, полученных сервером |

## H. EmsSettingsStore

| ID  | Сценарий | Исходные данные | Ожидаемый результат |

## W. EmsWorker

| ID  | Сценарий | Исходные данные | Ожидаемый результат |
|-----|----------|-----------------|---------------------|
| W01 | Нет запроса запуска | worker запущен | Рассылка не выполняется |
| W02 | Запуск | `RequestRun()` | Сразу `IsRunning = true`; прогон завершается с `Completed`, письма обработаны |
| W03 | Повторный запуск и остановка | сервер не отвечает; `RequestRun()` дважды, затем `RequestStop()` | Второй запрос отклонён; результат `Stopped` |
| W04 | Остановка без прогона | `RequestStop()` | `false` |
| W05 | Ошибка сервиса | `SmtpClient = null` | Результат `Failed`, `LastError` заполнен, новый запуск возможен |
