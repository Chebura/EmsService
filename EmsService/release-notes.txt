1.0.0
	+ Первая версия EmsService: Email Mass Sender в виде сервиса ASP.NET Core (.NET 10)
	+ Рассылка выполняется фоновым сервисом (BackgroundService) и запускается кнопкой в веб-интерфейсе
	+ Веб-интерфейс (HTTP, без аутентификации): настройки, группы получателей, тексты писем, задачи, журнал
	+ Остановка рассылки кнопкой с сохранением состояния задач
	+ Рассылка выполняется, пока все письма не будут отправлены либо не исчерпаются попытки или срок актуальности
	+ Переключатель светлой и тёмной темы интерфейса (по умолчанию — как в системе)
	+ Установщик для Windows (MSI): установка службы с автозапуском, ярлыки на веб-интерфейс на рабочем столе и в меню «Пуск»
	+ Проверка настроек при сохранении и проверка готовности перед запуском
	+ Настройки хранятся в файле emssettings.json, создаётся при первом запуске
	+ Отправка писем через MailKit (SSL/TLS: порт 465 — неявный TLS, остальные — STARTTLS)
	+ Логирование через NLog: файлы logs/ems-<дата>.log, консоль, вкладка «Журнал»
	+ Self-contained single-file публикация; работа на Windows и Linux, как служба Windows и systemd
	+ Документация: README.md, docs/USER-GUIDE.md (руководство пользователя), srs/SRS.md
	+ Unit-тесты EmsService.Tests (перенесены из EmailMassSender.Tests и дополнены)
	! Отличия от EmailMassSender:
		- удалены параметры HostRecycle и ExecutionTimeout, вместо них рассылка ждёт ближайшей повторной попытки
		- при выключенной повторной отправке каждому получателю даётся одна попытка (ранее попытки шли до конца срока актуальности)
		- состояние задачи сохраняется и при остановке посреди прохода, отправленные письма повторно не уходят
		- повреждённый файл задачи пропускается, а не обрабатывается повторно в каждом проходе
		- файлы задач читаются и записываются через System.Text.Json вместо Newtonsoft.Json (формат JSON прежний)
		- убрано дублирование имени задачи в журнале
